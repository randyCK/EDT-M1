# EDT filtré et synchronisé pour iPhone

Le dépôt récupère l'EDT, garde les événements des codes sélectionnés, puis publie un `.ics` en HTTPS. L'iPhone s'abonne à cette adresse et la même adresse reste valable quand le filtre change.

Matières actuelles : Droit pénal spécial, Droit des successions, Régime général de l'obligation, Histoire de la pensée politique, Histoire du droit de la famille, Histoire juridique de l'Orient.

Le filtre conserve tous les événements portant ces codes : CM, TD, séminaires, rattrapages, etc.

Pour modifier les matières : modifier `filter_config.json`, puis relancer l'action GitHub.
